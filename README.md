# Digital Bridge — генератор AI-сервисов

Одностраничный визард: выбираете роль, один из готовых AI-сервисов (или свою идею),
отвечаете на несколько вопросов и получаете готовый промт для [Vibe AI](https://code.vibe42.kz).

Работает полностью в браузере, без бэкенда и внешних запросов. Визуал собран на
дизайн-системе KT AI из папки `design-system/`.

## Запуск локально

Иконки подгружаются через `fetch`, поэтому страницу нужно открывать по HTTP, а не как файл:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## GitHub Pages

Деплой настроен через `.github/workflows/pages.yml`. В настройках репозитория
(Settings → Pages) выберите Source: **GitHub Actions**, после чего каждый пуш в
`main` публикует сайт.
